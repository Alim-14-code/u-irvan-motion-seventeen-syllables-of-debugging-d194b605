# Seventeen Syllables of Debugging

A haiku about debugging, in the classic 5-7-5 form — three lines, seventeen syllables, one typo.

![rank](https://make.fun/badge/u-irvan-motion-seventeen-syllables-of-debugging-d194b605/Alim-14-code/u-irvan-motion-seventeen-syllables-of-debugging-d194b605/rank.svg) ![competition](https://make.fun/badge/u-irvan-motion-seventeen-syllables-of-debugging-d194b605.svg) ![also entered](https://make.fun/badge/news-image-20261123.svg)

## The haiku

```
Stack trace at midnight
the bug hides where I looked twice
it was a typo
```

## How to run

```sh
node main.ts
```

This writes the haiku to `/output/entry.txt`.
